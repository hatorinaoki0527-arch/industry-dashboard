# 行业观察 · 私人研究室

GitHub Pages 提供公开页面外壳，J-Quants 行情仅以 AES-256-GCM 密文发布。输入专用密码后在浏览器内解密；不属于 GitHub 原生私有 Pages，也不是服务器账号登录。旧密文下载后无法撤回，请使用长且唯一的密码。

私有仓库 industry-dashboard-data 每天北京时间19:17、21:17获取真实日线。JQUANTS_API_KEY、DASHBOARD_PASSWORD、部署密钥只放私有仓库 Secrets。原始行情与完整历史只保留在私有仓库。

网页展示最近最多120个交易日：日本33行业有效样本等权涨跌、日期比较、个股量价及行业成交额前10历史。不是东证行业指数，成交额榜不是原代表／活跃评分。原评分字段不齐时不生成名单。中国与美国入口独立，未接行情显示待接入。

自动发布使用短期 delivery/* 分支，仅加入密文和公开网页文件；Pages 发布后删除临时分支，不将每日大文件累积进 main 历史。已上传密文可能仍被 GitHub 保留，删除分支不是数据撤回机制。更新前端 main 后，在私有仓库手动运行 J-Quants Daily，选择 publish_only 即可重新发布。

浏览器需要支持 Web Crypto 和 DecompressionStream。密码只用于当前页面，不写入本地存储。项目无第三方浏览器依赖。
